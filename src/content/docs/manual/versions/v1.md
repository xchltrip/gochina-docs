## What this page is for

v1 is the contract for the paths below. Every JSON body includes `apiVersion` with the value `v1`.

## Current paths

| Method | Path |
| --- | --- |
| GET | `/v1/token` |
| GET | `/v1/tours` |
| GET | `/v1/tours/{code}` |
| GET | `/v1/embed.js` |

## Compatible changes

v1 may add fields. A field that is already documented is not removed, renamed, or given a new meaning. `wholesalePrice` becoming a value later is an added field.

A shape that cannot follow those rules would be published under `/v2`. `/v1` would keep working. v2 is not available.

## What is not a version change

A price change, an itinerary edit, or taking a tour down is content, not a new API version. After a tour is unpublished or loses its formal code, the detail returns HTTP 404 with `available` set to `false`, and the list omits it. There is no push notification. Call the API again, or read this page.

`/v1/embed.js` may later change the card’s appearance. The JSON fields stay the stable contract.
