## What this page is for

v1 is the contract for the paths below. Every JSON body includes `apiVersion` with the value `v1`.

The machine-readable copy of this contract is <https://docs.gochina.cool/openapi/v1.yaml>. The pages on this site and that file describe the same fields.

## Current paths

| Method | Path | Credential |
| --- | --- | --- |
| POST | `/v1/token` | App Secret in the JSON body |
| GET | `/v1/tours` | Bearer token |
| GET | `/v1/tours/{tourCode}` | Bearer token |
| GET | `/v1/tours/{tourCode}/card` | Publishable Key |
| GET | `/v1/prices` | Bearer token |
| GET | `/v1/currencies` | Bearer token |
| GET | `/embed.js` and `/v1/embed.js` | None. The script calls the card. |

## Changes from the first published v1

These three behaviors changed because the first contract had not been adopted by outside applications:

- The tour list is paginated. Omitting `page` returns the first page, not every tour.
- Tokens are created with `POST /v1/token`. The secret is not accepted in the URL, and the success body is no longer wrapped in `code`, `msg`, and `data`. `expiresInSeconds` is a duration in seconds.
- A Publishable Key can call only the card and load the embed script. It cannot read the list, the detail, or prices.

Field names that were already published have been replaced by the names in [Read tours](/manual/tours/read/) and [Reference prices](/manual/tours/prices/). `websiteUrl` is the GoChina page. `durationDays` is the number of days. Reference prices are read only from `/v1/prices`.

## Compatible changes

From this page onward, v1 may add fields. A field that is already documented is not removed, renamed, or given a new meaning.

A shape that cannot follow those rules would be published under `/v2`. `/v1` would keep working. v2 is not available.

## What is not a version change

A price change, an itinerary edit, or taking a tour down is content, not a new API version. After a tour is unpublished or is not in the current itinerary structure, the detail returns HTTP 404 with `available` set to `false`, and the list omits it. There is no push notification. Call the API again, or read this page.

`/embed.js` may later change the card’s appearance. The JSON fields stay the stable contract.
